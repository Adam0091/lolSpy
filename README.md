# League of Spies — FastAPI

Онлайн-игра «Шпион» по League of Legends. Комната создаётся по кнопке, игроки подключаются по ссылке `/room/КОД`. Ведущий выбирает категории — чемпионов, скины, предметы или любую комбинацию. Сервер случайно выбирает объект из объединённого пула и случайно назначает шпионов.

## Запуск локально

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn main:app --reload
```

Откройте http://127.0.0.1:8000. Для проверки онлайн-игры используйте разные браузеры/устройства. На одном устройстве можно открыть несколько приватных окон.

## Как играть

1. Создайте комнату и отправьте друзьям ссылку.
2. Каждый вводит свой никнейм. Ссылка ведёт прямо в комнату.
3. Нужны минимум 3 игрока.
4. Ведущий выбирает число шпионов и одну или несколько категорий: чемпионы, скины, предметы.
5. Обычные игроки видят загаданное имя, изображение и, для предметов, описание. Шпионы видят только свою роль и пытаются вычислить объект по разговору.
6. Каждый игрок отдельно бросает кубик (1–6). Большее число — раньше в порядке ходов; после всех бросков порядок раскрывается всем.
7. Игроки по очереди говорят ассоциацию к секретному слову и нажимают «Передать ход». Идёт до 5 кругов.
8. После 5 кругов (или раньше, если большинство предложит) начинается голосование: кто шпион. Можно выбрать нескольких игроков или «Никого».
9. Когда все проголосовали, раскрываются объект, настоящие шпионы и итоги голосования. Ведущий может запустить новый раунд.

Роли и чемпион назначаются случайно. Игрок не может посмотреть чужую роль через обычный интерфейс/API.

## Деплой на Railway

1. Загрузите содержимое папки в GitHub-репозиторий.
2. В Railway создайте проект из этого репозитория.
3. Railway распознает Python-проект и команду запуска из `railway.json`.
4. Добавьте переменную окружения `SECRET_KEY` со случайным длинным значением.
5. После деплоя откройте выданный домен. Ссылки приглашения будут формироваться на текущем домене.

## Важно для хостинга

Текущая версия хранит комнаты в памяти процесса. Это удобно для первого запуска, но **комнаты исчезнут при перезапуске или redeploy**, а несколько инстансов Railway не будут делиться состоянием. Для устойчивого публичного запуска нужно вынести комнаты/игроков в Redis или PostgreSQL и добавить WebSocket или периодический опрос уже с общим хранилищем. Сейчас клиенты обновляют состояние примерно раз в 1,8 секунды. Для одного Railway-инстанса и дружеских игр это годится как MVP.

Список чемпионов, облики и предметы загружаются из Riot Data Dragon при запуске. Изображения берутся напрямую с CDN Riot Games, в проекте они не хранятся. Описания предметов берутся из локализованного файла данных Data Dragon выбранной версии. Riot отмечает, что обновление Data Dragon может запаздывать относительно игрового патча. Если Data Dragon недоступен, игра может запуститься с резервным списком чемпионов, но скины и предметы могут быть недоступны.
